What each execution path establishes

Path Demonstration or test Qualification boundary
Rust/WASM + WebGPU The device page's 21-case suite: two portable CPU cases and 19 GPU cases, including compute, buffers, rendering, semantic/tensor operations, IQ-power processing and queue leases. All 21 must pass for WebGPU qualification. Reports identify the actual build and adapter; unavailable cases remain failures of qualification.
Rust/WASM + WebGL2 Automatic rendering fallback after an unavailable WebGPU adapter, with an offscreen triangle and checked pixel readback. Rendering is recorded separately. WebGL2 does not supply the WebGPU compute-shader API.
Portable WASM CPU NQuin ABI/parity/filter/sort and Forge deterministic shader generation with Naga validation. Establishes those CPU/compiler results; GPU execution is reported by the GPU cases.
Native graphics and compute Resource, render/compute, validation and platform tests; feature-example image checks; prepared Vulkan correctness and allocator checks. Applies to the runner/backend used. Prepared allocation measurements cover the instrumented Rust path, not all driver or OS allocations.
Shader compiler Naga parser/error tests, validation tests, translation snapshots and target-validator checks. Shader validity and translation evidence; running a generated shader requires a target execution test.
Physical sensors and vendor accelerators Provider contracts and target-specific device, SDK, permission and calibration checks. DSP, NPU, SDR and native device integrations require qualification on their selected deployment.

Run the browser tests · Test suites and commands · Conformance coverage. The device demonstrations are application tests, not WebGPU CTS certification.

Installable app and device tools

Offline WASM app and bounded local reports

The installable app launches the same Rust/WASM library in a standalone window. Its service worker caches a revision-checked bundle; reports record display mode, source revision and offline state. Both ordinary tabs and installed windows can use these browser APIs. Manifest specification.

Explicitly save, export or delete reports in origin-private storage: at most 16 reports, 256 KiB each and 4 MiB total. Persistence is requested separately and the browser reports its grant. User-cleared site data can still remove stored reports. File System Standard · Storage Standard · Try local storage.

BLE, cameras and browser network evidence

Explicitly choose a BLE device by service, operate a selected GATT characteristic, write up to 512 bytes and retain up to 32 notifications. Network evidence includes exposed online state and performance estimates; it does not enumerate Wi-Fi SSIDs or MAC addresses. Web Bluetooth · Network Information API.

Camera permission is requested on explicit start with audio disabled. Select an exposed camera and ingest a bounded frame in Rust/WASM. Infrared or thermal classification remains unknown from an ordinary video stream. Installed mode retains browser permission and capability requirements for all these operations. Try device access.
