A small, bounded suite for phones, tablets and desktops. Portable tests run without a GPU; browser WebGPU tests run when the browser exposes a suitable adapter. If no WebGPU adapter is available, a separate Rust/WASM WebGL2 rendering and pixel-readback test runs automatically.

This exercises Etalon's compiled Rust/WASM API over the browser's WebGPU implementation. It is not the full WebGPU CTS and does not test native Vulkan, DX12, Metal, DSP/NPU or sensor hardware. Coverage explained.

Install the WASM test app

Install Etalon, open it from your launcher, and run the same Rust/WASM tests in app mode. Reports identify the display mode and app revision so you can compare installed and browser runs. Installation keeps browser GPU security rules in force.

If your browser does not offer the install button, use its menu: Install app or Add to Home screen. On iOS, use Share, then Add to Home Screen.

WebGL2 rendering fallback

        

          When WebGPU adapter acquisition returns unavailable, Etalon tries its
          WebGL2 backend for rendering and verified pixel readback. This uses
          the compiled Rust/WASM library. WebGL2 has no compute-shader API, so
          the WebGPU compute cases remain unavailable and the WebGPU
          qualification stays failed. Browser security settings are unchanged.

        WebGPU adapter-acquisition failure prevents WebGPU workloads from
        running. The report retains Etalon requests, independent browser
        controls and debug events; it does not establish a driver or policy
        cause. Native Rust tests qualify a separate backend and do not establish
        mobile browser support.
      

      

        The exported report includes the exact source commit, library version,
        browser/device metadata and a local Rust debug log (up to 128 events,
        512 message bytes per event, with a 64 KiB serialized budget) and
        reports dropped entries. Adapter acquisition controls are diagnostic
        evidence, not GPU passes. Browser GPU-process and driver-internal logs
        are not available to this page. Nothing is uploaded automatically.
