A small, bounded suite for phones, tablets and desktops. Portable tests run without a GPU; browser WebGPU tests run when the browser exposes a suitable adapter.

This exercises Etalon's compiled Rust/WASM API over the browser's WebGPU implementation. It is not the full WebGPU CTS and does not test native Vulkan, DX12, Metal, DSP/NPU or sensor hardware. Coverage explained.

Tests request only the resources they use and report required, adapter and device limits. A requested compatibility level is not proof of a physical mobile GPU or that an older browser honored the option.

Use it across systems

  1. Open this HTTPS page on the device you want to test, then press Run.
  2. Keep browser settings and power/thermal conditions with your notes. An unsupported case reports a missing capability rather than a successful test.
  3. Download the local JSON report if you want to compare or share evidence. Pin the reported source revision in your application.

If WebGPU is unavailable, use a browser/OS combination that exposes it, or run the native Rust tests for that system. Do not infer native driver coverage from these browser results.
