Run the implementation on your device

The installable test app runs the compiled Rust/WASM library. Its reports identify the build, browser, device information and actual execution path. Keep results locally, export them, or compare browser and installed-app runs.

Execution path What the app exercises
Browser WebGPU Compute, buffer and texture readback, validation, rendering, NQuin radix/sieve, tensor operations, IQ-power processing and resource leases.
WebGL2 rendering fallback Etalon rendering and verified pixel readback when a WebGPU adapter is unavailable. WebGPU compute remains a separate requirement.
Portable WASM CPU NQuin wire/parity/filter/sort checks and deterministic Forge shader generation and Naga validation.
Browser devices and storage Explicit BLE and camera access, exposed network metadata, offline app loading and a bounded local report store.

WebGPU qualification requires all 21 suite cases to pass, including 19 GPU cases. A successful WebGL2 render is recorded separately. Open the runner · See native, compiler and browser coverage.
