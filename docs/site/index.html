Start with a small dependency

The default sensing facade provides portable contracts, runtime coordination and signal primitives. Select device and acceleration providers through features. 

[dependencies]
etalon-sense = { git = "https://github.com/mediaprophet/etalon.git",
                 branch = "dev", features = ["cpu", "sdr"] }

Etalon packages are consumed through Git or a local sibling checkout; they are not published to crates.io. See a complete I/Q example and provider choices.

Libraries without a universal policy

Etalon provides sensing mechanisms. Applications own identity, permissions, inference and storage. QualiaDB can bind observations into its semantic and custody systems; environmental or telescope-style observations need no invented human subject.
