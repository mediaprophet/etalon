# Etalon 0.0.3 candidate

This candidate repairs browser GPU extension execution and exposes failures through the Rust/WASM device suite. It does not replace the immutable 0.0.2 tag.

- NQuin GPU radix/sieve use 64-thread workgroups and asynchronous caller-buffered readback.
- Tensor attention now has a matching 96-byte/six-binding ABI; top-k handles tails, ties and invalid candidates. Forward arenas check explicit byte budgets and support asynchronous token readback.
- Queue-bound leases retain resources until completion. Browser callbacks accept browser-local handles while preserving native thread-safety bounds.
- Browser limits distinguish absent properties from explicit zero; required limits remain strict. Adapter rejection names/messages and Core/Compatibility/Auto attempts are retained.
- Float-canvas capabilities move out of device creation into explicit asynchronous queries. Android accelerator discovery is bounded and does not claim runtime or hardware execution.
- The device page runs 20 Rust/WASM cases, including 18 GPU cases. Missing, failed or unrun GPU cases fail qualification. ADB/CDP support retains local physical-device receipts.
