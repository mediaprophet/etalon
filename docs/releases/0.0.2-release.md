# Etalon 0.0.2 final release

Package version: **0.0.2**. Final source tag: **v0.0.2-release**.
The published v0.0.2 prerelease tag remains unchanged for historical consumers.
The final GitHub release records the exact source commit and completed qualification runs.

## Library scope

- Native graphics and compute through Vulkan, Metal, DX12 and GLES; browser WebGPU through Rust/WASM, with explicit Core/Compatibility adapter requests and preserved acquisition errors.
- Naga shader parsing, validation and translation; deterministic WGSL Forge generation and certification.
- NQuin wire/parity/sieve/radix operations, GPU tensor top-k/attention/forward execution, rendering and HUD contracts, worker and agent execution coordination.
- Prepared native Vulkan execution with fixed resources and explicit admission requirements.
- Portable sensing contracts, signal processing, camera/radio/device providers and isolated vendor adapters; authority and custody remain host responsibilities.
- Installable WASM test application, bounded local OPFS receipts, offline assets tied to one revision, explicit camera/BLE controls, and actionable startup recovery receipts.

## Qualification and limits

Release promotion requires the complete CI matrix, Docs build and browser execution gates, and independent Git-consumer compilation on the exact release commit. The GitHub release links the completed runs; inspect those records for their platform and backend scope.

The browser suite has 21 cases (two portable CPU and 19 GPU). Hosted WebGPU Core/Compatibility and separate WebGL2 render/readback tests exercise real browser APIs; hosted software GPU results are not physical-phone WebGPU qualification. Synthetic failures are tested separately and never counted as GPU execution.

On the physical Pixel 10 Pro XL, WebGL2 rendering/readback, installed-app storage/offline operation, front/rear camera sampling and startup failure/recovery were exercised. WebGPU adapter acquisition returned null: WebGPU compute remains unavailable in that tested browser environment. WebGL2 is a rendering fallback, not a compute substitute. BLE API availability was observed; physical GATT acquisition was not qualified. Camera frames do not establish IR, heart-rate or identity inference. Private device receipts remain local.

These checks are not WebGPU CTS certification or universal DSP/NPU/SDR hardware qualification. Native/vendor feature gates and licensing requirements remain explicit. See [mobile evidence and disposition](../mobile-resolution-2026-11-01.md).

## Consumer and branch policy

```toml
[dependencies]
etalon = { git = "https://github.com/mediaprophet/etalon.git", tag = "v0.0.2-release" }
```

Use the same tag for related Etalon packages. `latest` and `stable` advance only to a qualified release, `v0.0.2.x` is the qualified maintenance line, and `dev` holds subsequent development. Cargo.lock preserves a resolved branch commit until explicitly updated. GitHub Pages publishes from stable. No crates.io publication is implied.

Licensing is unchanged: Etalon additions/modifications retain CC BY-NC-ND 4.0, with upstream and third-party notices and isolated vendor requirements preserved.
