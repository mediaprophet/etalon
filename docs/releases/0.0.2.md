# Etalon 0.0.2 — historical prerelease snapshot

For the final release, see [0.0.2 final release](0.0.2-release.md). This document preserves earlier development evidence.

**The requested mobile GPU outcome is incomplete.** Subsequent physical tests failed adapter acquisition. The existing tag is preserved as historical evidence; [continuing development](0.0.2-development.md) remains version 0.0.2 on dev. The historical capabilities below do not establish mobile qualification.

This release advances Etalon as a reusable Rust graphics and compute library for
QualiaDB and other applications, with native backends and a browser WebGPU path
compiled to WebAssembly. Sensing is an optional extension of that foundation.

## What changed

- A broader [capability guide](https://mediaprophet.github.io/etalon/capabilities.html)
  explains the wgpu-derived foundation, Etalon fixes, WGSL Forge, NQuin operations,
  tensor execution, rendering, WASM worker transport and optional sensing providers.
- The [device test page](https://mediaprophet.github.io/etalon/testing.html) executes
  13 Rust/WASM cases: NQuin layout/filtering/sorting, deterministic Forge generation
  and validation, buffer initialization and readback, compute dispatch boundaries,
  changed inputs, error scopes, invalid-input validation and rendered pixel checks.
  JavaScript loads the module and presents results; the library operations and
  assertions execute in Rust/WASM.
- Browser tests can request core or compatibility adapters, negotiate only their
  workload's required resources and report adapter/device limits. This allows
  mobile browsers to exercise their actual WebGPU implementation without imposing
  desktop-sized buffer or texture requirements.
- Native Vulkan prepared execution reuses fixed upload, command, submission and
  readback resources. Sensing IQ-power execution uses the prepared provider with
  explicit admission, bounds, poisoning and retirement behavior.
- Optional device integration includes RTL-SDR receive support and an isolated
  vendor workspace with portable DSP routing, a Hexagon IQ-power service and
  synchronous FastRPC host transport. Vendor runtime and hardware requirements
  remain explicit.

## Use the release

Etalon is distributed through this Git repository; workspace crates are not
published to crates.io. Pin consumers to the release tag or its exact commit:

```toml
[dependencies]
etalon = { git = "https://github.com/mediaprophet/etalon", tag = "v0.0.2" }
```

Select features appropriate to the target; see the
[getting-started guide](https://mediaprophet.github.io/etalon/getting-started.html)
and [API documentation](https://mediaprophet.github.io/etalon/doc/etalon/index.html).
Upstream wgpu types and Etalon types are distinct.

## Qualification

The release must be tagged only after CI and documentation deployment succeed at
that exact source commit. The browser deployment gate requires all 13 cases to
pass on its software WebGPU adapter; unsupported GPU cases do not satisfy that
gate. Native software Vulkan qualification and browser software WebGPU
qualification are separate results.

Physical Android/iOS GPU execution has not been recorded for this release.
Cross-compilation, desktop browser execution and viewport dimensions do not prove
that hardware. Run the published suite on the target phone to obtain a local JSON
report containing the source revision, requested feature level, exposed limits
and individual outcomes. No report or sensor data is uploaded automatically.
These focused tests are not the full WebGPU CTS. DSP/NPU/SDR hardware qualification
also remains deployment-specific.
